# Board support package

Files needed to run stock NVIDIA JetPack on this board:

- Pinmux spreadsheet export and generated device-tree includes
- Device-tree overlay / patches (cameras, CAN, UARTs, IMU)
- Flashing configuration

Goal: keep this as a small, documented diff on top of NVIDIA's P3768 reference so it can track new JetPack releases quickly.
